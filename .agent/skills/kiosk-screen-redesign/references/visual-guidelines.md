# Kiosk 立式大屏 UI/UX 视觉与交互设计规范

## 1. 核心色彩体系 (Color System)

| 色彩角色 | 色值 (HEX) | 适用场景与心理映射 |
| :--- | :--- | :--- |
| **品牌主色 (Primary Blue)** | `#2F54EB` (深蓝 `#1D39C4`) | 核心行动按钮 (CTA)、聚焦边框、光标、强调标签 |
| **会员黑金尊享色 (Gold Accent)** | `#F59E0B` / `#FFE58F` | 👑 尊享会员卡、皇冠微光、折扣标签、特权提示 |
| **主背景与卡片底色** | `#FFFFFF` / `#F8FAFC` | 终端主界面背景、弹窗卡片背景、输入框底色 |
| **深色暗幕遮罩 (Scrim)** | `rgba(15, 23, 42, 0.65)` | 弹窗呼出时的暗色磨砂遮罩（凸显中央操作区） |
| **文字层级 - 标题大字** | `#0F172A` (Slate-900) | 弹窗主标题、输入框大数字、按键数字 (24~30px) |
| **文字层级 - 正文说明** | `#475569` (Slate-600) | 副标题、输入框标签、选项文字 (13~16px) |
| **文字层级 - 辅助弱化** | `#94A3B8` (Slate-400) | 占位文字、未激活状态说明、底部弱提示 (11~13px) |

## 2. 实体触觉按键规范 (Tactile Keypad Design)

立式触摸一体机（通常为 21.5"、27" 或 32"）没有实体机械微动开关。为了给站立操作的顾客提供极佳的触控确定感，**严禁使用无边界纯文本悬浮数字**，必须遵循以下规则：

1. **实体卡片容器**：
   - 键盘按键尺寸：建议单键宽度 `136~148px`，高度 `60~68px`，间距 `12~14px`。
   - 圆角半径：`14px`。
   - 边框：`1.2px solid #E2E8F0`（清空键为 `#FFCCC7`）。
   - 微立体阴影：`box-shadow: 0 3px 6px rgba(0, 0, 0, 0.04);`
2. **触控动效与回弹**：
   - 按下状态（Active）：轻微缩放 `scale(0.97)`，背景微深 `rgba(47, 84, 235, 0.08)`。
   - 在 Flutter 中使用 `InkWell` 配备 `splashColor: Color(0x1F2F54EB)`。
3. **功能键配色区分**：
   - 数字键 `1~9`、`0`：纯白底卡片 + 深色粗体数字（`#0F172A`, 26~28px bold）。
   - `清空` 键：浅粉底卡片（`#FFF1F0`）+ 红色文字（`#F5222D`）。
   - `退格` 键：浅灰底卡片（`#F8FAFC`）+ 深灰矢量退格图标。

## 3. 长串数字格式化规范 (Number Grouping)

1. **手机号（11位）**：
   - 必须使用 **`3-4-4` 空格动态分段**：例如 `138  8888  8888`。
   - 字号：`24~26px`，字体推荐 `monospacedDigitSystemFont` 等宽数字，杜绝数字晃动。
   - 右侧配备胶囊状态徽章：未满显示 `X/11位`，满位瞬间变绿 `✓ 11/11位`。
2. **商品 EAN-13 条形码（13位）**：
   - 必须使用 **`3-4-6` 空格动态分段**：例如 `880  1043  014830`。
   - 右侧配备胶囊状态徽章：`X/13位`，满位瞬间变绿 `✓ 13/13位`。

---

## 4. 按钮状态驱动规则 (State Constraints)

1. **禁用态 (Disabled)**：
   - 输入为空或未达到有效位数时，底部的提交按钮必须**严格禁用**。
   - 样式：浅灰底 `#E2E8F0`，无阴影，文字为淡灰 `#94A3B8`。
   - 提示文案明确化：如 `请输入 11 位手机号码` 或 `请输入 8~13 位条形码`。
2. **激活态 (Enabled)**：
   - 达到有效位数瞬间，平滑过渡为激活态。
   - 样式：皇家蓝垂直渐变（`#2F54EB` -> `#1D39C4`），伴随深色投射阴影（`0 8px 18px rgba(47, 84, 235, 0.38)`）。
   - 提示文案驱动化：如 `立即登录 / 快速建档 ➔` 或 `✓ 确认录入商品 ➔`。
